# Pedestrian model credits

Converted for the web (meshes simplified to about 5,000 triangles, textures resized to 1024 px and stored as
WebP, the dancing animation removed from Manuel). In the game every person walks with Nathan's walking
animation and stands with Sophia's idle animation.
